# 동요샘 노래상자

동요샘 선생님들이 지은 창작동요를 전국 교실에서 함께 부르는 웹앱입니다.

- 오늘의 동요: 계절에 맞는 곡을 하루 한 곡씩 소개
- 노래 찾기: 발표회별, 주제별, 학년군별로 곡 찾기
- 전국 무대: 반이 부른 곡에 도장을 찍으면 지역 점수가 올라가는 시도 지도와 순위, 이어 부르기 릴레이
- 동요샘 차트: 반마다 한 달에 한 곡씩 투표
- 우리 반: 가입 신청·로그인, 계정 하나에 여러 반, 우리가 모은 동요 스티커, 반 칭호, 노래 탐험 지도
- 곡마다 우리 반 가사 바꾸기와 좋아요

## 구조
- 화면: 이 저장소의 index.html (GitHub Pages)
- 서버(Collector.gs): 동요샘 운영진 구글 시트 하나에 설치. 선생님 계정(가입 신청·승인·로그인), 반별 기록, 곡 목록, 전국 현황을 모두 맡음
- national.json: 서버 주소

설치 방법은 설치안내.txt 를 보세요.
주소에 ?s= 없이 열면 예시 기록으로 돌아가는 체험 모드입니다.

만든 사람: 음악적체육인
