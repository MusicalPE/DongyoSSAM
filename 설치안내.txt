동요샘 노래상자 설치 안내
==========================

[1] 운영진이 한 번만: 전국 수집기 만들기
  1. 구글 시트를 새로 만들고 이름을 "동요샘 노래상자 수집기"로 정합니다.
  2. 확장 프로그램 > Apps Script 를 열고, 들어 있는 내용을 지운 뒤 Collector.gs 내용을 모두 붙여 넣고 저장합니다.
  3. 배포 > 새 배포 > 유형: 웹 앱
     - 다음 사용자로 실행: 나
     - 액세스 권한이 있는 사용자: 모든 사용자
     배포 후 나오는 웹 앱 주소(…/exec)를 복사합니다.
  4. 그 주소를 DongyoSSAM 저장소 national.json 의 collector 칸에 넣습니다.
  5. 웹 앱 주소를 브라우저로 한 번 열면 시트에 곡 목록·설정·반·바꾼 가사·릴레이 기록 탭이 생깁니다.
     (탭은 처음 기록이 들어오거나 전국 현황을 처음 부를 때 자동으로 만들어집니다)

  운영진 메뉴
  - 노래상자 화면 맨 아래 '운영진'을 누르고 운영진 비밀번호로 들어갑니다. (처음 비밀번호 1234, 들어가자마자 6자 이상으로 바꿔 주세요)
  - 곡 관리: 새 곡 올리기, 곡 고치기, 숨기기
  - 가사 확인: 학교에서 올린 바꾼 가사를 공개하거나 숨기기
  - 릴레이: 릴레이 이름과 곡 정하기
  - 참여 반: 알맞지 않은 반을 전국 무대에서 숨기기
  - 운영진에게는 바뀐 운영진 비밀번호만 알려 주면 됩니다. 시트를 공유하지 않아도 돼요.

  아래 일은 운영진 메뉴 대신 수집기 시트에서 직접 해도 됩니다.
  - 곡 목록 탭: 한 줄에 한 곡. 예시 곡 8개를 실제 곡으로 바꿔 주세요. 곡번호는 한 번 정하면 바꾸지 않습니다.
    영상 주소·악보 주소 칸에 https 로 시작하는 주소를 넣으면 화면에 버튼이 생깁니다.
    숨김 칸에 O 를 적으면 그 곡이 화면에서 빠집니다.
  - 설정 탭: 릴레이 이름과 릴레이 곡번호. 릴레이 이름을 바꾸면 새 릴레이가 처음부터 시작됩니다.
  - 바꾼 가사 탭: 학교에서 올린 가사가 쌓입니다. 공개 칸에 O 를 적은 가사만 전국에 보입니다.
  - 반 탭: 숨김 칸에 O 를 적으면 그 반 기록을 전국 무대에서 뺍니다.
  - 고친 내용은 2분 안에 화면에 반영됩니다. 바로 보고 싶으면 편집기에서 clearBoardCache 를 실행합니다.

[2] 선생님마다: 학교 시트에 껍데기 설치
  1. 구글 시트를 새로 만듭니다 (예: "우리 반 노래상자").
  2. 확장 프로그램 > Apps Script 에 Shell.gs 내용을 모두 붙여 넣고 저장합니다.
  3. 배포 > 새 배포 > 웹 앱 (나로 실행, 모든 사용자)
  4. 배포 주소를 열면 설치 확인 화면이 나옵니다. "노래상자 열기"를 누릅니다.
  5. 노래상자의 우리 반 탭에서 선생님 로그인(처음 비밀번호 1234) 후
     반 이름(지역 두 글자 + 학교 이름 + 반, 예: 서울햇살초 5-1)과 지역을 저장하고 비밀번호를 바꿉니다.
  6. 열린 주소를 즐겨찾기해 두고 수업 때 그 주소로 엽니다.

  학교 시트에는 도장·투표·릴레이·바꾼 가사·좋아요 탭이 생기고, 누를 때마다 전국 수집기로 우리 반 상태가 보내집니다.
  주소 끝에 ?s= 없이 열면 예시 기록으로 돌아가는 체험 모드입니다.
