동요샘 노래상자 설치 안내 (한 시트 방식)
=========================================

선생님들은 아무것도 설치하지 않아요. 운영진이 서버 시트 하나만 만들면 됩니다.

[1] 운영진이 한 번만: 서버 만들기
  1. 구글 시트를 새로 만들고 이름을 "동요샘 노래상자"로 정합니다.
  2. 확장 프로그램 > Apps Script 를 열고, 들어 있는 내용을 지운 뒤 Collector.gs 내용을 모두 붙여 넣고 저장합니다.
  3. 운영진 비밀번호 정하기: 코드 아래쪽 setOperatorPassword 안의 "새비밀번호"를 원하는 비밀번호로 바꾸고 저장한 뒤,
     위쪽 함수 목록에서 setOperatorPassword 를 골라 실행 버튼을 누릅니다. (처음 한 번 권한 허용 창이 뜹니다)
  4. 배포 > 새 배포 > 유형: 웹 앱
     - 다음 사용자로 실행: 나
     - 액세스 권한이 있는 사용자: 모든 사용자
     배포 후 나오는 웹 앱 주소(…/exec)를 복사합니다.
  5. 그 주소를 DongyoSSAM 저장소 national.json 의 collector 칸에 넣습니다. (주소를 보내 주시면 넣어 드려요)
     넣기 전까지 노래상자는 예시 기록으로 돌아가는 체험 모드예요.

[2] 운영진 메뉴 (노래상자 화면 맨 아래 '운영진')
  - 계정: 가입 신청을 승인하거나 거절합니다. 승인된 선생님만 로그인할 수 있어요.
          비밀번호를 잊은 선생님께는 '임시 비밀번호'를 눌러 나온 비밀번호를 알려 드립니다.
          '비밀번호 문의 이메일'에 적은 주소가 로그인 화면에 보여요.
  - 곡 관리: 새 곡 올리기, 곡 고치기, 숨기기 (처음엔 예시 곡 8개가 들어 있어요)
  - 가사 확인: 반에서 올린 바꾼 가사를 공개하거나 숨기기
  - 릴레이: 릴레이 이름과 곡 정하기 (이름을 바꾸면 새 릴레이가 처음부터 시작)
  - 참여 반: 알맞지 않은 반을 전국 무대에서 숨기기

[3] 선생님이 쓰는 방법
  1. 노래상자 주소(https://musicalpe.github.io/DongyoSSAM/)로 들어가 '우리 반' 메뉴에서 '처음이에요 · 가입 신청'
     아이디, 비밀번호, 이름, 학교, 지역을 적습니다.
  2. 운영진이 승인하면 로그인합니다.
  3. '반 만들기'로 우리 반을 만듭니다. 전담 선생님은 반을 여러 개 만들고 골라 가며 쓸 수 있어요.
     반 이름은 전국 무대에 보이니 지역 두 글자 + 학교 이름 + 반으로 적어 주세요. (예: 서울햇살초 5-1)
  4. 노래를 부른 뒤 스티커 붙이기, 이달의 노래 투표, 릴레이 이어받기, 바꾼 가사 올리기를 합니다.

[참고]
  - 시트에는 계정·반·곡 목록·설정·바꾼 가사·릴레이 기록 탭이 자동으로 생겨요. 시트에서 직접 고쳐도 됩니다.
  - 비밀번호는 암호처럼 바꿔서 저장되어 시트에서도 원래 비밀번호를 알 수 없어요.
  - 학생 이름 같은 개인정보는 저장하지 않아요.
  - 고친 내용은 2분 안에 화면에 반영됩니다. 바로 보고 싶으면 편집기에서 clearBoardCache 를 실행합니다.
